# M0 — AI Spike

## Hypothesis

A small progressive-inference pipeline can transform unstructured social-video evidence into high-confidence place candidates and verified geographic entities without sending every full video to a multimodal model.

## Spike sequence

### M0.1 — Contracts and failure modes

- Typed source, evidence, candidate, resolved-place and analysis contracts.
- Social adapters explicitly model inaccessible media.
- First YouTube Short is a URL-only fallback eval.

### M0.2 — Local media ingestion

Input: local MP4/MOV fixture supplied by the user.

- inspect media
- extract audio
- produce transcript
- sample frames only if transcript/metadata is insufficient
- retain only temporary derived artifacts

### M0.3 — Structured extraction

Implement an LLM-backed `PlaceExtractor` with Zod structured output. It must return 0..N candidates and evidence for each candidate. Prompt version, model, latency, input/output tokens and estimated cost become part of the trace.

### M0.4 — Place resolution

Implement the first real `PlaceProvider`. Candidate names and geographic hints are searched externally. Address/coordinates are only marked verified after provider resolution. Ambiguous matches remain `needs_review`.

### M0.5 — Evals

Grow from the first case to 10–15 real videos, then 50. Measure extraction precision/recall, resolution accuracy, category accuracy, manual correction rate, multimodal escalation rate, latency and cost per successfully resolved place.

## Progressive inference

```text
metadata
  -> enough evidence? extract
  -> transcript
      -> enough evidence? extract
      -> selected frames
          -> enough evidence? extract
          -> multimodal reasoning
```

Each escalation must be justified by missing/ambiguous evidence rather than being the default.

## First test

`https://www.youtube.com/shorts/19Ls-ZMU86c`

For URL-only M0, expected behavior is currently `media_required`. The next meaningful test is the same content supplied as a local video fixture, allowing us to validate transcription/extraction without making scraping a product dependency.
